# Проверки публичной версии — 24 сентября 2026

- `pytest -q`: **43 passed** (35 прежних сценариев и 8 проверок переносимой OAuth-конфигурации).
- `pip check`: зависимости совместимы.
- IMAP в автоматических тестах заменён фиктивным объектом; RSA-ключи временные.
- Проверяются static auth, разделение read/write, Host/Origin, MCP initialize/tools, BODY.PEEK, UIDVALIDITY, ограничения размера, MOVE без delete/EXPUNGE fallback, сокрытие исключений.
- OAuth: RS256, issuer, resource audience, Client ID, сроки, scopes/claims, отказ для ID token и неверных подписей, кеш JWKS, отказ при сбое обновления.
- Добавлена проверка HTTPS-конфигурации OAuth: credentials/query/fragment и неверный путь ресурса не допускаются, пустой Client ID отклоняется при включении OAuth.

Проверки выполнены на Windows / Python 3.12. Они не являются аудитом безопасности.
Персональная предшествующая установка подтверждена владельцем как работающая на ZimaOS с ChatGPT и Authentik. Публичная версия отличается вынесенными в env адресами и Client ID и отсутствием персонального extra_hosts.

Docker image публичной версии в этой среде не собирался; реальный OAuth-вход и операции записи публичной версии на живом ящике здесь не выполнялись. После установки нужны локальный и внешний smoke test, oauth_check при включённом OAuth, вход через клиент. Запись проверяется отдельно на тестовом письме. Health endpoint подтверждает только работу процесса.
